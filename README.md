# IELTS 词汇高速筛选 V1

这是一个纯本地网页：不用安装、不联网、不注册。词库与学习记录都留在当前浏览器中。

## 最简单的使用方式

1. 双击打开 `index.html`。
2. 点击“选择 List”，例如选 `List 2` 到 `List 6`，就只学习这 5 个 List。
3. 看到单词后，直接按键盘 `1`、`2`、`3` 或 `4`（手机直接点四个大按钮）。
4. 查看中文释义后，按 `Enter` / 空格，或点击“下一个”。
5. 随时点“导出记录”，把 JSON 或 CSV 文件上传给 ChatGPT 分析。

## 说明

- 首次打开已经内置了“雅思词汇乱序版”去重后的词条，并自动分成约 100 词一个 List。自动分组会尽量避开相邻、词形明显相关的派生词；内置词库来自没有 List 标题的原始文本。
- `P` 可以暂停 / 继续；关闭网页也不会丢进度。
- “数据与词库管理”可以导入自己的 **List 格式 TXT**，并单独保存该词库的学习记录；不会拿一个无结构 TXT 猜测 List。
- 导出时可直接下载 JSON/CSV，也可用支持的浏览器选择一个文件夹，直接把两份记录保存进去。管理页还能从多份 JSON/CSV 或整个文件夹合并旧记录。
- 不要用浏览器的“清除网站数据”功能，否则本地学习记录会一起被清除；请先导出 JSON 备份。

## 自定义词库的固定格式

下载并修改 [词库格式模板.txt](词库格式模板.txt)。每个 List 的标题必须是 `## List 数字`；标题之下每行一个词条，以 **Tab 键** 分隔三列：`英文单词`、`词性`、`中文释义`。

```text
## List 1
delve<Tab>vi.<Tab>钻研；探究
exact<Tab>adj.<Tab>准确的；精确的

## List 2
elicit<Tab>vt.<Tab>引出；引起
```

这意味着近义词、派生词要不要放在同一个 List，完全由你在 TXT 里排版决定；网页不会把它们强行拆开或改顺序。

## 词库来源与使用

内置词条根据用户指定的“雅思词汇乱序版”文本解析、去重。原公开来源说明词库仅供学习、不得商用，且词库版权归原权利人所有。因此建议将 GitHub 仓库设为**私有**，仅作个人学习和备份使用。

## 文件说明

- `index.html`：直接打开的入口。
- `vocabulary.js`：内置、已去重的离线词库。
- `app.js`：学习记录、统计和导出功能。
- `styles.css`：界面样式。
